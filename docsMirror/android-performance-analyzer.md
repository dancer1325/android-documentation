Featured

###  Vulkan debug markers 

APA supports Vulkan debug annotations for render passes, allowing you to view Render Pass names you set from your codebase directly in the trace view. 

![](https://developer.android.com/static/android-performance-analyzer/images/project-workflow.png)

Featured

###  Project-based workflow 

A dedicated project sidebar helps manage and compare multiple traces, which is ideal for A/B testing.
